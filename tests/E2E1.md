# E2E1 baseline (manual checklist)

Automated part: `tests/e2e_phase1.sh` (pty-driven bash matrix + edge top-up,
doctor coexistence probe). This file is the manual part the script cannot do.

## Real-terminal dogfood (bash)

1. `eval "$(./target/debug/amem init bash)"` in a REAL terminal (GNOME
   Terminal / KiTTY /.macOS Terminal — with distro integrations loaded).
2. Run 5 commands including one failure (`false`) and one secret
   (`export DEMO_TOKEN=secret123`).
3. `./target/debug/amem ingest --once` → `{"ingested":5,...}`.
4. `./target/debug/amem doctor` → `records(shell): 5`, no `secret123` anywhere.
5. Unset: remove the eval line (or close the terminal); no residue.

## Expected evidence

- Recall count equals commands typed; secret redacted `[redacted:secret-assign]`.
- Shell startup time unaffected (hook path is one fast append).
