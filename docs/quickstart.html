Quickstart

Five minutes from zero to searchable history. Everything stays on your machine.

1. Install

$ curl -fsSL https://nitishagar.github.io/agent-memory/install.sh | bash

This downloads the binary for your OS into ~/.local/bin (created if needed). Prefer cargo? cargo install --git https://github.com/nitishagar/agent-memory amem-cli

2. Hook up your shell

$ amem init bash >> ~/.bashrc   # or zsh, fish, powershell
$ exec "$SHELL"

Every command you run is now recorded with exit code, cwd, and duration. Secrets (--password, AKIA… keys, bearer tokens) are redacted before they touch disk.

3. Ingest and search

$ amem ingest --once
$ amem search "cargo test"
[shell #4] cargo test --workspace (exit 0) @a1b2c3d4

ingest --once drains the spool plus your agent transcripts (Claude Code, Cursor, OpenCode, pi, ZCode, Codex) into the store. search recalls newest-first across the whole team union once you sync.

4. Give your agent memory

Add amem to your agent's MCP config (per-agent snippets), then ask it "what did I try yesterday and why did it fail?".

5. Sync with your team (optional)

$ amem sync --endpoint https://sync.internal:8443 --trust-new

See self-host sync to run the server. First contact pins the server certificate (TOFU); later changes refuse loudly instead of leaking data.

Check health any time with amem doctor — read-only, always exit 0, safe to paste (mostly; it lists installed tools).
