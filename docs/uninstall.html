Uninstall

amem keeps no daemons, no launchers, and no files outside the three places below. Removal leaves zero rc residue.

1. Remove the shell hook

Delete the amem init line you added to your rc file (~/.bashrc, ~/.zshrc, ~/.config/fish/config.fish, or your PowerShell $PROFILE), then restart your shell.

2. Remove the data

$ rm -rf ~/.local/share/agent-memory   # Linux
$ rm -rf ~/Library/Application\ Support/agent-memory   # macOS
$ rm -rf ~/.agent-memory   # fallback / portable

Export first if you want to keep anything: amem export --vault ~/memory-vault produces plain Markdown that opens in Obsidian.

3. Remove the binary

$ rm ~/.local/bin/amem   # or: cargo uninstall amem-cli

4. Remove agent configs (optional)

Delete the agent-memory entry from each MCP config you edited (see Agents). Agents simply stop offering the tools.
