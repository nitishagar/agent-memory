Agents

amem serves six MCP tools over stdio: mem_search, mem_read, mem_list, mem_write, mem_delete, mem_context. Text by default, format: "json" on request. Recorder streams are read-only — only notes mutate, and mutations are checksum-guarded (stale guards refuse, never silent last-write-wins).

Claude Code

~/.claude.json, under mcpServers:

{
  "agent-memory": { "command": "/home/you/.local/bin/amem", "args": ["mcp"] }
}

Codex

~/.codex/config.toml:

[mcp_servers.agent-memory]
command = "/home/you/.local/bin/amem"
args = ["mcp"]

Cursor

~/.cursor/mcp.json:

{
  "mcpServers": {
    "agent-memory": { "command": "/home/you/.local/bin/amem", "args": ["mcp"] }
  }
}

OpenCode / ZCode

opencode.json (or zcode.json) in your project:

{
  "mcp": {
    "agent-memory": {
      "type": "local",
      "command": ["/home/you/.local/bin/amem", "mcp"]
    }
  }
}

pi

pi reads MCP servers from its settings file — add an entry with command /home/you/.local/bin/amem and args ["mcp"], same shape as above.

Use the absolute path to your amem binary (which amem). Agents spawn it per session; there is no daemon to manage.
